# Afterfall: Последний выживший

Изометрическая survival-игра для **Android**, созданная на **Godot 4.3 (GDScript)** и оптимизированная под смартфон **iQOO Z9 5G** (Snapdragon 7 Gen 3, 8 ГБ ОЗУ, экран 120 Гц, горизонтальная ориентация).

## Основные особенности

- **Изометрический процедурный мир 100×100** с генерацией по `Seed`, 6 типами местности, связной дорожной сетью и 7 исследуемыми локациями (заброшенный магазин, разрушенная АЗС, старый склад, заброшенный квартал, стоянка выживших, северные руины, восточный терминал).
- **Стриминг чанков (10×10)** и Y-sorting — активны только ближайшие чанки вокруг игрока для стабильного FPS без перегрева на Snapdragon 7 Gen 3.
- **Выживание и прогрессия**: здоровье, голод, жажда, энергия, тепло/комфорт, 4 прокачиваемых навыка (*Собирательство*, *Ремесло*, *Строительство*, *Выживание*).
- **Инвентарь, хранилища и крафт**: 24 слота (до 32 с рюкзаком), категории, быстрая панель, 32 предмета, 21 рецепт крафта (ручной, у костра, на рабочем столе).
- **Строительство убежища**: 11 построек с изометрическим предпросмотром — костёр, пол, стены, хранилище (16 слотов), кровать (сон на 6 часов), навес от дождя, рабочий стол, сборщик дождевой воды, огородная грядка, фонарный столб и каменная печь.
- **Цикл дня/ночи и динамическая погода**: утро, день, вечер, ночь, тёплое освещение костров и фонарей, ясно/облачно/дождь/гроза, атмосферный звук.
- **Надёжные сохранения**: JSON в `user://afterfall_save.json` с автоматической резервной копией (`afterfall_save.bak`), автосохранением и ручным сохранением.
- **Сенсорное управление Android**: мультитач виртуальный джойстик, контекстная кнопка взаимодействия, быстрая панель, щипок двумя пальцами для зума и пресеты качества в настройках.

## Инструкция по сборке APK через GitHub Actions и Termux

### 1. Создание репозитория на GitHub

1. Откройте [GitHub](https://github.com) в браузере на телефоне и войдите в аккаунт.
2. Нажмите **+** → **New repository**.
3. Введите название `Afterfall`, выберите **Public** или **Private** и нажмите **Create repository** (не добавляйте README/gitignore при создании).
4. Скопируйте HTTPS-ссылку репозитория (например, `https://github.com/ВАШ_НИК/Afterfall.git`).

### 2. Загрузка проекта через Termux

Распакуйте архив `Afterfall.zip` в память телефона (например, в `/sdcard/Download/Afterfall`), затем откройте **Termux** и выполните:

```bash
pkg update && pkg upgrade -y
pkg install git -y
termux-setup-storage
```

Перейдите в папку проекта и отправьте код на GitHub:

```bash
cd ~/storage/downloads/Afterfall
git init
git branch -M main
git config user.name "Ваш Ник"
git config user.email "ваш@email.com"
git add .
git commit -m "Initial Afterfall Godot 4.3 Android project"
git remote add origin https://github.com/ВАШ_НИК/Afterfall.git
git push -u origin main
```

> При запросе пароля используйте **Personal Access Token (PAT)** из настроек GitHub (`Settings → Developer settings → Personal access tokens → Tokens (classic)` с правом `repo` и `workflow`).

### 3. Запуск автоматической сборки

Сборка запускается **автоматически** сразу после `git push` в ветку `main` (workflow `.github/workflows/android-build.yml`).
Также можно запустить её вручную: откройте репозиторий на GitHub → вкладка **Actions** → **Build Android APK (Godot 4.3)** → **Run workflow**.

### 4. Скачивание APK из Artifacts

1. Дождитесь зелёной галочки напротив завершённого запуска workflow (обычно 2–4 минуты).
2. Нажмите на название запуска и пролистайте вниз до раздела **Artifacts**.
3. Нажмите **Afterfall-Android-APK**, чтобы скачать ZIP-архив с `Afterfall-debug.apk`.

### 5. Установка APK на iQOO Z9 5G

1. Распакуйте скачанный архив `Afterfall-Android-APK.zip` в стандартном файловом менеджере.
2. Нажмите на `Afterfall-debug.apk`.
3. При первом запуске разрешите установку из неизвестных источников для файлового менеджера.
4. Нажмите **Установить** и запустите **Afterfall**!
